# AI Resume Builder

## Overview

AI Resume Builder is a web application that helps users create professional, ATS-friendly resumes in minutes using AI.

Instead of spending hours formatting resumes and deciding what to write, users can enter their details and receive AI-generated content suggestions, professional summaries, skills recommendations, and optimized resume sections tailored to their career goals.

The platform simplifies the resume creation process while helping users build resumes that stand out to recruiters and hiring managers.

---

## Problem Statement

Many job seekers struggle with:

* Writing professional resumes
* Creating ATS-friendly resume formats
* Choosing the right resume template
* Highlighting relevant skills and achievements
* Formatting resumes correctly
* Building resumes without prior experience

This project helps users create professional resumes quickly using AI-powered assistance and modern resume templates.

## Installation & Setup

### 1. Clone the Repository

```bash
git clone https://github.com/yourusername/AI-Resume-Builder.git
cd AI-Resume-Builder
```

### 2. Setup Frontend

```bash
cd Frontend
npm install
npm run dev
```

Create a `.env` file:

```env
VITE_API_URL=http://localhost:5000
VITE_CLERK_PUBLISHABLE_KEY=your_clerk_publishable_key
```

### 3. Setup Backend

```bash
cd BackEnd
npm install
node server.js
```

Create a `.env` file:

```env
GOOGLE_GEMINI_KEY=your_gemini_api_key
MONGODB_URI=your_mongodb_connection_string
PORT=5000
```
